Prerna Numerology PWA
======================

Files:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png
- icons/apple-touch-icon.png
- icons/favicon-32.png

INSTALL REQUIREMENTS
- Deploy the folder on HTTPS for normal production use.
- localhost also works for development.
- Desktop Chromium browsers can show an Install option once the manifest + service worker criteria are met.
- Android browsers can offer Install app / Add to Home screen.
- iPhone/iPad Safari: Share -> Add to Home Screen.

The supplied numerology wheel image is used for the PWA artwork and icons.

IMPORTANT:
A website cannot force-install itself. The browser controls whether and when its
install/add-to-home-screen UI is offered.
