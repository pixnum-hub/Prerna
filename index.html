Prerna

Numerology Calculator

Desktop Installation

Open this app over HTTPS (or localhost) in a supported browser. When the browser makes the PWA installable, use the Install Prerna button or the browser's install icon.

Mobile Home Screen

On Android Chrome, use the browser menu and choose Install app or Add to Home screen when offered. On iPhone/iPad Safari, use Share → Add to Home Screen.

Works Offline

The service worker caches the app shell and icons so the installed app can open again without a network connection.
